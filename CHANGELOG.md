# Changelog

Все заметные изменения проекта записываются в этот файл.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.0.0-rc.1] - 2026-11-03

### Added

- Ответы на анализ open source проекта hexlet-basics/exercises-python:
  `docs/github/opensource.ipynb` и `docs/github/opensource.py`.
- Скриншот закрытия pull request: `docs/github/images/close_pr.png`.
- Ответы на тест по GitHub: `docs/github/quiz.ipynb` и `docs/github/quiz.py`.
- `AUTHORS.md`: авторы проекта и благодарности участникам.
- `CODE_OF_CONDUCT.md` на основе Contributor Covenant 2.1.
- `SECURITY.md`: поддерживаемые версии и порядок сообщения об уязвимостях.
- `CHANGELOG.md`.

### Changed

- Ноутбук `github_quiz` переименован в `quiz`.
- `README.md` переписан по шаблону: задания, быстрый старт, структура
  репозитория, стандарты кода, участие в проекте, лицензия.

### Removed

- Из `README.md` убраны разделы «Улучшения репозитория», «Улучшения курсов» и
  «Улучшение организации», они перенесены в `AUTHORS.md`.

### Fixed

- Ссылка на лицензию в `CONTRIBUTING.md` теперь ведёт на `LICENSE`.
