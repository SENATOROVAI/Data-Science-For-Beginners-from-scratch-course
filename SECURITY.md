# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются только для актуального состояния ветки
`main` и последнего релиза.

| Версия | Поддерживается |
| --- | --- |
| `main` | ✅ |
| 1.0.x | ✅ |
| < 1.0 | ❌ |

## Как сообщить об уязвимости

Не сообщайте об уязвимостях в публичных issue, pull request или чатах курса.

1. Откройте вкладку **Security** репозитория и нажмите
   [Report a vulnerability](https://github.com/SENATOROVAI/Data-Science-For-Beginners-from-scratch-course/security/advisories/new)
   (private vulnerability reporting). Сообщение увидят только мейнтейнеры.
2. Если форма недоступна, напишите мейнтейнеру курса в Telegram
   [t.me/RuslanSenatorov](https://t.me/RuslanSenatorov).

Укажите в сообщении:

- описание уязвимости и её возможные последствия;
- файлы, версию или коммит, где она найдена;
- шаги для воспроизведения;
- предложения по исправлению, если они есть.

## Что будет дальше

- В течение 7 дней мейнтейнеры подтвердят получение сообщения.
- После проверки вы узнаете, принята уязвимость или отклонена.
- Принятая уязвимость исправляется в `main`, после чего информация о ней
  публикуется в GitHub Security Advisories. Автор сообщения указывается в
  благодарностях, если не против.
