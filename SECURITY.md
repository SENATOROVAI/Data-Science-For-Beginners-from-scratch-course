# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются только для последней версии из ветки
`main`.

| Версия | Поддерживается |
|---|---|
| `main` (последний релиз 1.x) | :white_check_mark: |
| более ранние версии | :x: |

## Как сообщить об уязвимости

**Не создавайте публичный issue** с описанием уязвимости.

1. Откройте [Security → Report a vulnerability](https://github.com/olehpatsan/Data-Science-For-Beginners-from-scratch-course/security/advisories/new).
2. Опишите проблему: какой файл или зависимость затронуты, как
   воспроизвести, к чему это может привести.
3. Отчёт увидит только мейнтейнер репозитория.

Ответ на сообщение — в течение 7 дней. Если уязвимость подтвердится, мы
выпустим исправление и опубликуем security advisory с благодарностью автору
отчёта (если он не против).

Уязвимости в исходном курсе сообщайте мейнтейнеру
[SENATOROVAI/Data-Science-For-Beginners-from-scratch-course](https://github.com/SENATOROVAI/Data-Science-For-Beginners-from-scratch-course).
